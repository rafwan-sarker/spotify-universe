    **Step 4: Create star-picking.ts (pure function, minimal Three.js import)**

    Create `src/lib/star-picking.ts`. This needs THREE.Vector3 and THREE.PerspectiveCamera types but for testing we'll mock them.

    ```typescript
    import type { StarData } from '@/lib/spotify/types'

    /**
     * Find the nearest star to a screen-space click position using NDC coordinates.
     * Bypasses raycaster entirely -- necessary because billboard vertex shader
     * moves geometry on GPU where CPU raycaster cannot follow (Pitfall 1).
     *
     * Performance: O(n) scan, <1ms for 10K stars. Only runs on click, not per-frame.
     */
    export function findNearestStar(
      ndcX: number,
      ndcY: number,
      stars: StarData[],
      projectFn: (position: [number, number, number]) => { x: number; y: number; z: number },
      maxNdcDistance: number = 0.05
    ): StarData | null
    ```

    The function iterates stars, calls `projectFn(star.position)` to get NDC coords, computes 2D distance `sqrt((projX - ndcX)^2 + (projY - ndcY)^2)`, returns the nearest star if distance < maxNdcDistance and z is between -1 and 1 (in front of camera). Returns null if no star qualifies.

    Note: `projectFn` is injected so the function is testable without a real THREE.Camera. In production, the caller creates `projectFn` from `camera.project(tempVec3)`.

    **Step 6: Create star-search.ts (pure search logic with fuse.js)**

    Create `src/lib/star-search.ts`. This extracts the fuse.js search logic into a testable pure module that SearchBar.tsx (Plan 03) will import.

    ```typescript
    import Fuse from 'fuse.js'
    import type { StarData } from '@/lib/spotify/types'

    const SEARCH_OPTIONS = {
      keys: [
        { name: 'name', weight: 0.7 },
        { name: 'artist', weight: 0.3 },
      ],
      threshold: 0.4,
      includeScore: true,
    } as const

    const MAX_RESULTS = 8

    /**
     * Create a Fuse.js search index from a StarData array.
     * Memoize this on the consumer side (useMemo keyed on stars.length).
     */
    export function createStarSearchIndex(stars: StarData[]): Fuse<StarData> {
      return new Fuse(stars, SEARCH_OPTIONS)
    }

    /**
     * Search stars using a pre-built Fuse index. Returns up to 8 results.
     * Empty query returns empty array (not all stars).
     */
    export function searchStars(index: Fuse<StarData>, query: string): StarData[] {
      if (!query.trim()) return []
      return index.search(query).slice(0, MAX_RESULTS).map(r => r.item)
    }
    ```
