    Create `src/components/canvas/FlightController.tsx` -- a single R3F component that replaces AutoOrbitCamera. Uses `useFrame` for all per-frame camera updates. Reads input from module-scope mutable state (NOT React state) per RESEARCH.md anti-pattern guidance.

    **Module-scope input state (zero re-renders):**
    ```typescript
    const keysPressed = new Set<string>()
    let mouseRightDown = false
    const mouseDelta = { x: 0, y: 0 }
    let scrollDelta = 0
    let lastInputTime = 0
    ```

    **Component structure:**
    ```typescript
    "use client"
    import { useEffect, useRef } from 'react'
    import { useFrame, useThree } from '@react-three/fiber'
    import * as THREE from 'three'
    import { useAppStore } from '@/lib/store'
    import {
      applyVelocityDamping,
      computeCruiseVelocity,
      shouldTransitionToIdle,
      FLIGHT_CONSTANTS,
    } from '@/lib/flight-math'
    import { deriveWarpVisuals, WARP_DURATION } from '@/lib/warp-visuals'
    ```

    **useEffect for event listeners:**
    Register keydown, keyup, mousedown, mouseup, mousemove, contextmenu (prevent default), and wheel event listeners. Key events on `window`, mouse events on `gl.domElement` (canvas).

    - keydown: add `e.code` to `keysPressed`, set `lastInputTime = performance.now() / 1000`. IMPORTANT: if `e.code` is 'Slash' or 'KeyK' with metaKey, do NOT add to keysPressed (these are search shortcuts, handled by DOM).
    - keyup: delete `e.code` from `keysPressed`
    - mousedown: if `e.button === 2` set `mouseRightDown = true`, set `lastInputTime`
    - mouseup: if `e.button === 2` set `mouseRightDown = false`
    - mousemove: if `mouseRightDown`, accumulate `mouseDelta.x += e.movementX`, `mouseDelta.y += e.movementY`, set `lastInputTime`
    - wheel: `scrollDelta += e.deltaY`, set `lastInputTime`
    - contextmenu: `e.preventDefault()` (suppress right-click menu on canvas)

    Clean up all listeners on unmount.

    **useFrame callback -- the state machine:**

    Use module-scope temp vectors to avoid allocations:
    ```typescript
    const _forward = new THREE.Vector3()
    const _right = new THREE.Vector3()
    const _velocity = new THREE.Vector3()
    const _warpStart = new THREE.Vector3()
    const _warpEnd = new THREE.Vector3()
    ```

    Use refs for mutable per-frame state:
    ```typescript
    const velocityRef = useRef(new THREE.Vector3())
    const yawRef = useRef(0)
    const pitchRef = useRef(0)
    const speedMultiplierRef = useRef(1.0)
    const warpStartPosRef = useRef(new THREE.Vector3())
    const idleAngleRef = useRef(0)
    ```

    Inside `useFrame(({ camera, clock }, delta)`:

    1. Read store state imperatively: `const state = useAppStore.getState()`
    2. If `state.searchOpen` is true, skip all input processing (search bar has focus)
    3. Switch on `state.cameraMode`:

    **Case 'idle':**
    - Gentle auto-drift: rotate camera around Y axis slowly. `idleAngleRef.current += FLIGHT_CONSTANTS.driftRotationSpeed * delta`. Apply rotation to camera position around a center point (camera's current lookAt target or origin).
    - If any key in `keysPressed` is a movement key (W/A/S/D/Arrow*) OR `mouseRightDown`: transition to 'cruising' via `state.setCameraMode('cruising')`

    **Case 'cruising':**
    - Apply mouse look (right-click drag): consume `mouseDelta`, apply to `yawRef` and `pitchRef`. Clamp pitch to `[-FLIGHT_CONSTANTS.pitchClamp, +FLIGHT_CONSTANTS.pitchClamp]`. Reset `mouseDelta` to {0,0} after consuming.
    - Apply yaw/pitch to camera quaternion: create quaternion from Euler(pitchRef, yawRef, 0, 'YXZ'), set `camera.quaternion.copy(quat)`.
    - Apply scroll wheel: `speedMultiplierRef.current = clamp(speedMultiplierRef.current - scrollDelta * 0.001, FLIGHT_CONSTANTS.minSpeedMultiplier, FLIGHT_CONSTANTS.maxSpeedMultiplier)`. Reset `scrollDelta = 0`.
    - Compute desired velocity from keys: use `computeCruiseVelocity(keysPressed, FLIGHT_CONSTANTS.cruiseSpeed * speedMultiplierRef.current)`. Extract camera's forward and right vectors. Build velocity vector: `forward * result.forward + right * result.strafe`.
    - If keys are pressed, set `velocityRef.current` toward desired velocity. If no keys, apply damping: `velocityRef.current` components via `applyVelocityDamping`.
    - Move camera: `camera.position.addScaledVector(velocityRef.current, delta)`.
    - Check idle transition: if `shouldTransitionToIdle(performance.now() / 1000 - lastInputTime)` AND velocity magnitude < 0.1, transition to 'idle'.

    **Case 'warping':**
    - On first frame of warp (warpProgress near 0): capture current camera position into `warpStartPosRef`.
    - Advance warp progress: `const newProgress = state.warpProgress + delta / WARP_DURATION`. Clamp to [0, 1].
    - Update store: `useAppStore.setState({ warpProgress: newProgress })`.
    - Derive visuals: `const visuals = deriveWarpVisuals(newProgress)`.
    - Apply FOV: `camera.fov = 60 + visuals.fovOffset`. Call `camera.updateProjectionMatrix()`.
    - Lerp camera position: `camera.position.lerpVectors(warpStartPosRef.current, targetPos, easeProgress)` where `easeProgress` uses smoothstep on newProgress for natural feel. Target position is `state.warpTarget.position` offset by [0, 2, 8] (slightly above and behind the star for a good viewing angle).
    - On arrival (newProgress >= 1.0): reset FOV to 60, call `updateProjectionMatrix()`, transition to 'inspecting' via `setCameraMode('inspecting')`. If warpTarget.starId exists, find the matching star in `state.stars` and call `setSelectedStar(star)`.

    **Case 'inspecting':**
    - Gentle slow orbit around the selected star position (similar to idle drift but centered on the star). Tiny radius orbit so the view subtly moves.
    - If any movement key pressed: `setSelectedStar(null)`, transition to 'cruising'.
    - (Warp triggers from clicking another star or search are handled externally via store.startWarp, which sets mode to 'warping' -- the next frame picks it up.)

    **Component returns `null`** (no JSX, purely imperative).

    **Step 1: Create warp streak GLSL shaders**

    Create `src/shaders/warp-streaks.ts` exporting `warpStreakVertex` and `warpStreakFragment` as string constants (same pattern as `star-shaders.ts` -- Turbopack cannot do ?raw GLSL imports).

    **Vertex shader (`warpStreakVertex`):**
    ```glsl
    uniform float uStreakStretch;  // 0 to 5, from deriveWarpVisuals
    uniform float uTime;

    attribute float aAngle;       // Random angle around the forward axis (0 to 2*PI)
    attribute float aRadius;      // Random distance from center (0.5 to 3.0)
    attribute float aSpeed;       // Random speed multiplier (0.8 to 1.2)

    varying float vAlpha;
    varying float vProgress;      // 0 at tail, 1 at head -- for gradient

    void main() {
      // Position particle on a cylinder around the camera forward axis
      float angle = aAngle;
      float radius = aRadius;

      // Base position in a ring
      vec3 pos = vec3(
        cos(angle) * radius,
        sin(angle) * radius,
        0.0
      );

      // Stretch along Z axis (camera forward) based on warp progress
      float stretch = uStreakStretch * aSpeed;
      // position.z from the geometry (-0.5 to 0.5 for a PlaneGeometry) becomes the streak length
      pos.z += position.z * stretch * 10.0;

      // Move streaks forward over time for motion feel
      pos.z -= mod(uTime * aSpeed * 20.0, 40.0) - 20.0;

      vAlpha = smoothstep(0.0, 0.3, 1.0 - abs(position.z * 2.0));  // Fade at head and tail
      vProgress = position.z + 0.5;  // 0 at tail, 1 at head

      gl_Position = projectionMatrix * modelViewMatrix * vec4(pos, 1.0);
    }
    ```

    **Fragment shader (`warpStreakFragment`):**
    ```glsl
    uniform float uOpacity;       // 0 to 0.8, from deriveWarpVisuals

    varying float vAlpha;
    varying float vProgress;

    void main() {
      // White at head, cyan at tail -- gradient along streak
      vec3 white = vec3(1.0, 1.0, 1.0);
      vec3 cyan = vec3(0.0, 0.94, 1.0);  // #00f0ff
      vec3 color = mix(cyan, white, vProgress);

      float alpha = vAlpha * uOpacity;
      if (alpha < 0.01) discard;

      gl_FragColor = vec4(color * alpha, alpha);  // Premultiplied alpha for additive blending
    }
    ```

    **Step 2: Create WarpStreaks R3F component**

    Create `src/components/canvas/WarpStreaks.tsx`:

    ```typescript
    "use client"
    import { useRef, useMemo } from 'react'
    import * as THREE from 'three'
    import { useFrame } from '@react-three/fiber'
    import { useAppStore } from '@/lib/store'

    import { warpStreakVertex, warpStreakFragment } from '@/shaders/warp-streaks'
    ```

    Component creates a `<points>` geometry with 800 streak particles. Each particle is defined by per-instance attributes:
    - `aAngle`: random float 0 to 2*PI
    - `aRadius`: random float 0.5 to 3.0
    - `aSpeed`: random float 0.8 to 1.2

    Use a `BufferGeometry` with `PlaneGeometry(0.02, 1, 1, 1)` for each streak (thin tall rectangle) or use a simple line approach with Points and stretch in the shader. The simpler approach: use a `BufferGeometry` with 800 vertices, each representing a streak center point, and use `gl_PointSize` for rendering, but that limits streak length. Better approach: use an InstancedBufferGeometry with a thin `PlaneGeometry(0.02, 1)` base, instanced 800 times.

    **Recommended approach -- InstancedMesh with thin planes:**

    ```typescript
    const STREAK_COUNT = 800

    // Pre-compute random attributes once
    const { angles, radii, speeds } = useMemo(() => {
      const angles = new Float32Array(STREAK_COUNT)
      const radii = new Float32Array(STREAK_COUNT)
      const speeds = new Float32Array(STREAK_COUNT)
      for (let i = 0; i < STREAK_COUNT; i++) {
        angles[i] = Math.random() * Math.PI * 2
        radii[i] = 0.5 + Math.random() * 2.5
        speeds[i] = 0.8 + Math.random() * 0.4
      }
      return { angles, radii, speeds }
    }, [])
    ```

    Create the geometry with instanced buffer attributes for aAngle, aRadius, aSpeed. Base geometry is a `PlaneGeometry(0.02, 1)` (thin, 1 unit tall, stretched by shader).

    ShaderMaterial uniforms: `uStreakStretch` (float), `uOpacity` (float), `uTime` (float).
    Material properties: `transparent: true`, `blending: THREE.AdditiveBlending`, `depthWrite: false`, `side: THREE.DoubleSide`, `toneMapped: false`.

    **useFrame callback:**
    - Read `cameraMode` and `warpProgress` from store via `getState()`
    - If `cameraMode !== 'warping'`, set mesh visibility to false (or set opacity to 0)
    - If `cameraMode === 'warping'`, derive visuals from warpProgress: `const { streakStretch, streakOpacity } = deriveWarpVisuals(warpProgress)`
    - Update uniforms: `material.uniforms.uStreakStretch.value = streakStretch`, `material.uniforms.uOpacity.value = streakOpacity`, `material.uniforms.uTime.value = clock.elapsedTime`
    - Position the streaks group at the camera's position and orient along camera's forward direction so streaks always radiate from screen center: `group.position.copy(camera.position)`, `group.quaternion.copy(camera.quaternion)`
