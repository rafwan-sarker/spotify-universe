    **Step 1: Create src/lib/galaxy-stats.ts**

    Export these pure functions (per D-11, D-12, Research Pattern 5):

    ```typescript
    export interface GalaxyStats {
      totalStars: number
      genreCount: number
      dominantGenre: string      // Display name (e.g., "Hip-Hop")
      dominantGenreId: string    // Lowercase ID (e.g., "hip-hop")
      dominantPercent: number    // 0-100 integer
      personality: string        // One of the 5 personality types
    }

    export interface GalaxyBounds {
      minX: number
      maxX: number
      minZ: number
      maxZ: number
    }
    ```

    **computeGalaxyStats(stars: StarData[], genres: GenreCluster[]): GalaxyStats**
    - Count total stars
    - Count unique genres represented in stars
    - Find dominant genre by counting stars per genre
    - Compute dominant percentage as `Math.round((maxCount / total) * 100)`
    - Look up display name from genres array (find by id)
    - Call computePersonality for personality label
    - Return GalaxyStats object

    **computePersonality(stars: StarData[]): string** (per D-12)
    - Build genre distribution: `Record<string, number>` from stars
    - Compute dominantPct = max genre count / total
    - If dominantPct > 0.5: return "Genre Loyalist"
    - Count active genres (genres with at least 1 star)
    - If dominantPct < 0.3 AND activeGenres >= 6: return "Eclectic Explorer"
    - Count high-brightness stars (brightness > 0.6)
    - If highBrightness / total > 0.6: return "Mainstream Voyager"
    - If highBrightness / total < 0.3: return "Deep Diver"
    - Default: return "Time Traveler"

    **computeGalaxyBounds(genres: GenreCluster[]): GalaxyBounds**
    - Iterate genre centroids, find min/max of X (index 0) and Z (index 2) values
    - Add 20-unit padding on each side for minimap margin
    - Return { minX, maxX, minZ, maxZ }

    **projectToMinimap(worldPos: [number, number, number], bounds: GalaxyBounds, mapSize: number): { x: number; y: number }**
    - Project X to minimap x: `((worldPos[0] - bounds.minX) / (bounds.maxX - bounds.minX)) * mapSize`
    - Project Z to minimap y: `((worldPos[2] - bounds.minZ) / (bounds.maxZ - bounds.minZ)) * mapSize`
    - Return { x, y }

    **Step 4: Create src/components/ui/MiniMap.tsx (per D-16, D-17, D-18, D-19)**

    "use client" component rendering a native 2D `<canvas>` element with its own requestAnimationFrame loop.

    **Why NOT inside R3F Canvas:** Performance isolation, bloom doesn't affect minimap, purely 2D visualization (per Research Pattern 4).

    **Structure:**
    - Render a `<canvas>` element wrapped in a positioned div
    - Positioning: `fixed top-20 right-4 z-10` (top-right, below profile menu which is at top-4)
    - Canvas size: 150x150 CSS pixels, 300x300 device pixels (2x for retina)

    **Drawing loop (per Research Pattern 4 example):**
    - Use `useEffect` to start a requestAnimationFrame loop.
    - Read genres from `useAppStore.getState().genres` (imperative, not reactive -- per Research anti-pattern advice).
    - Read camera position from `sharedCameraRef.current.position` (set by FlightController).
    - Compute camera yaw: `Math.atan2(-forward.x, -forward.z)` where forward is camera's negative Z axis in world space. Extract via `camera.getWorldDirection(tempVec)`.

    **Drawing each frame:**
    1. Clear canvas with `clearRect(0, 0, size, size)`
    2. Fill background `rgba(0, 0, 20, 0.85)` (per D-18)
    3. Draw border `rgba(0, 240, 255, 0.3)` 1px stroke
    4. Compute bounds once from genres (memoize with useRef), use `computeGalaxyBounds`
    5. For each genre: project centroid to 2D using `projectToMinimap`, draw circle with genre color (convert [r,g,b] 0-1 to `rgb(r*255, g*255, b*255)`), radius 4px
    6. If `sharedCameraRef.current` exists: project camera position to 2D, draw white triangle pointing in camera yaw direction

    **Triangle drawing:**
    ```typescript
    ctx.save()
    ctx.translate(camX, camY)
    ctx.rotate(-yaw)
    ctx.beginPath()
    ctx.moveTo(0, -6)  // tip
    ctx.lineTo(-4, 4)  // bottom-left
    ctx.lineTo(4, 4)   // bottom-right
    ctx.closePath()
    ctx.fillStyle = '#ffffff'
    ctx.fill()
    ctx.restore()
    ```

    **Cleanup (per Research Pitfall 4):** Store RAF ID in a ref. Cancel in useEffect cleanup:
    ```typescript
    useEffect(() => {
      let rafId: number
      function draw() { /* ... */ rafId = requestAnimationFrame(draw) }
      rafId = requestAnimationFrame(draw)
      return () => cancelAnimationFrame(rafId)
    }, [])
    ```
