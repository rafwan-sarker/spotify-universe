    Update `src/app/page.tsx` to be the galaxy landing page per D-01 (the product IS the landing page).

    Replace the placeholder content with:

    ```typescript
    import dynamic from "next/dynamic"
    import { auth } from "@/auth"

    const GalaxyScene = dynamic(
      () => import("@/components/canvas/GalaxyScene"),
      { ssr: false }
    )

    export default async function HomePage() {
      const session = await auth()

      return (
        <main className="relative h-screen w-screen overflow-hidden" style={{ background: "#000005" }}>
          <GalaxyScene isAuthenticated={!!session} />
        </main>
      )
    }
    ```

    Key points:
    - Per Pitfall 2: dynamic import with ssr: false prevents Three.js SSR crashes
    - Per D-12: The `style={{ background: "#000005" }}` ensures the dark background shows instantly before JS loads (no white flash). The inline style is intentional -- Tailwind classes load after JS.
    - Per D-01: No splash page, no login gate. The canvas IS the first and only screen.
    - The page is an async server component that checks auth status and passes it to the client canvas.
    - DOM overlays (banner, profile menu) will be added in Plan 03 -- this plan focuses on the 3D scene only.
