Create the server-side API proxy layer that forwards authenticated Spotify requests. Six route handlers cover all data sources (saved tracks, top tracks, playlists, recently played, individual artists). Each route reads the JWT access token via getToken() and forwards to Spotify's API, passing back rate limit headers.

Purpose: The access token is server-side only (security). The client fetch orchestrator (Plan 03) calls these proxies instead of Spotify directly. Also updates OAuth scopes to include playlist and recently-played access (per D-01).

Output: Six API route files + updated scopes file.

    2. Create src/lib/spotify/api-helpers.ts with a shared helper to reduce boilerplate across all 6 route handlers:
    ```typescript
    import { getToken } from "next-auth/jwt"
    import { NextRequest, NextResponse } from "next/server"

    /**
     * Extracts the Spotify access token from the JWT cookie.
     * Returns null if unauthenticated or token missing.
     */
    export async function getSpotifyToken(request: NextRequest): Promise<string | null> {
      const token = await getToken({ req: request })
      return token?.accessToken ?? null
    }

    /**
     * Proxies a request to the Spotify API with the user's access token.
     * Handles 401 (unauthorized) and 429 (rate limit) responses.
     */
    export async function spotifyFetch(
      request: NextRequest,
      spotifyUrl: string
    ): Promise<NextResponse> {
      const accessToken = await getSpotifyToken(request)
      if (!accessToken) {
        return NextResponse.json({ error: "Unauthorized" }, { status: 401 })
      }

      const response = await fetch(spotifyUrl, {
        headers: { Authorization: `Bearer ${accessToken}` },
      })

      if (response.status === 429) {
        const retryAfter = response.headers.get("Retry-After") ?? "5"
        return NextResponse.json(
          { error: "Rate limited", retryAfter: parseInt(retryAfter) },
          { status: 429, headers: { "Retry-After": retryAfter } }
        )
      }

      if (!response.ok) {
        const errorBody = await response.text()
        return NextResponse.json(
          { error: `Spotify API error: ${response.status}`, details: errorBody },
          { status: response.status }
        )
      }

      const data = await response.json()
      return NextResponse.json(data)
    }
    ```

    IMPORTANT per RESEARCH.md Pitfall 1: Use getToken() from "next-auth/jwt", NOT auth(), because the session callback strips the access token. getToken() reads the raw JWT from cookies.
